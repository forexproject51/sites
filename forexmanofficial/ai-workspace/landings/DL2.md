# DL2 — Join the Movement

## Purpose

Marketing landing: hero, community pitch, feature pills, Telegram CTA, feature row, VIP callout — static HTML/CSS only.

| Role | Path |
|------|------|
| view | `DL2/index.html` |

## User Stories

- User reads benefits and community size; taps CTA to join.
- User sees “Forexman VIP” upsell block.

## UI Design

Layout: Centered column on dark gradient + noise overlay; stacked hero, pills, CTA, horizontal feature cards, VIP strip.
Elements: Gradient headline span, emoji feature icons, `tracker` link on CTA (attribute for tracking hooks).
Patterns: Single-page scroll-free viewport emphasis; teal/purple ambient gradients.
Notes: Inline SVG on CTA; no JS.
