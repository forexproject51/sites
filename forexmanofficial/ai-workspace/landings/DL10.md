# DL10 — Watch the Signals Hit Live

## Purpose

Signal-board aesthetic: grid canvas, animated feed of “signals”, timing labels, online tick, CTA.

## Files

| Role | Path |
|------|------|
| view | `DL10/index.html` |

## User Stories

- User watches signal cards appear in a live-style feed.
- User is driven to Telegram for full access.

## Key Functions

| Name | Line | Input | Output | Purpose |
|------|------|-------|--------|---------|
| `resizeCanvas` | 348 | none | none | Match canvas to window. |
| `drawGrid` | 353 | none | none | Draw background grid. |
| `makeSigItem` | 409 | sig, timeStr | node / HTML | Creates one signal row. |
| `animateFeed` | 450 | none | none | Advances feed animation. |
| `tickOnline` | 470 | none | none | Updates online indicator. |

## Dependencies

| Type | Name | Path |
|------|------|------|
| external | Google Fonts | URL in `<head>` |

## UI Design

Layout: Chart-room / terminal vibe; feed list; canvas; sticky CTA.
Elements: Signal rows with pair/direction mockups; clocks/timestamps.
Patterns: `requestAnimationFrame` or intervals coordinating feed + grid redraw.
Notes: Demo data only unless backed by API.
